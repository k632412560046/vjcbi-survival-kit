# VJCBI Survival Kit Landing Page V3

## Xem nhanh
Mở `preview.html` để xem ngay mà không phụ thuộc file CSS/ảnh bên ngoài.

## Chỉnh sửa bản website
- `index.html`: cấu trúc và text chính
- `styles.css`: màu, spacing, font, layout
- `app.js`: interaction
- `assets/hero-banner.png`: ảnh hero
- `assets/vjcbi-logo-header.png`: logo/header

## Màu chính
Trong `styles.css`, sửa các biến ở đầu `:root`.

## AI link
Tìm `https://chatgpt.com/` trong `index.html` và thay bằng link AI Assistant thực tế.
